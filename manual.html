2เริ่มต้นใช้งาน เจ้าของ

  1. เปิดแอปที่ piggybabe-gmail.github.io/fit-routine → กด เข้าสู่ระบบด้วย Google (เจ้าของ) → เลือกบัญชี Google ของคุณ
  2. เข้าครั้งแรก ถ้าหน้าจอขึ้นกล่อง เริ่มต้นใช้งาน ให้กด นำเข้าไฟล์ข้อมูลเดิม เพื่อดึงข้อมูลจากแอปเดิม หรือกด เริ่มจากค่าตั้งต้น
  3. เพิ่มลงหน้าจอโฮม ใน Safari กดปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
  4. แอปบนหน้าจอโฮมล็อกอินแยกจาก Safari ให้ไปที่ ตั้งค่า → สมาชิก → เพิ่มชื่อของคุณ เลือกสิทธิ์ อุปกรณ์อื่นของฉัน → คัดลอกลิงก์ → เปิดแอปบนหน้าจอโฮม แล้ววางลิงก์ในช่อง มีลิงก์เชิญ? → ใช้ลิงก์เชิญ → พิมพ์ชื่อ
  5. เชื่อม LINE เพื่อรับแจ้งเตือน: ตั้งค่า → บัญชี → เชื่อม LINE (รายละเอียดอยู่ในข้อ 10)
  6. เชิญเทรนเนอร์: ตั้งค่า → สมาชิก → พิมพ์ชื่อเทรนเนอร์ → สิทธิ์ เทรนเนอร์ → เพิ่มสมาชิก → คัดลอกลิงก์ → ส่งลิงก์ให้เทรนเนอร์ทาง LINE
ชื่อต้องตรงกัน ชื่อที่ตั้งตอนเพิ่มสมาชิก คือชื่อที่เทรนเนอร์ต้องพิมพ์ตอนเข้าใช้ ควรใช้ชื่อสั้นที่พิมพ์ง่าย เช่น "โค้ชบอม"

3เริ่มต้นใช้งาน เทรนเนอร์

ส่งส่วนนี้ให้เทรนเนอร์อ่านได้เลย ใช้เวลาประมาณ 2 นาที ไม่ต้องสมัครสมาชิกหรือตั้งรหัสผ่าน

  1. เปิด ลิงก์เชิญ ที่ได้รับทาง LINE ใน Safari หรือ Chrome (ถ้าลิงก์เปิดในเบราว์เซอร์ของ LINE ให้กด ⋯ → เปิดในเบราว์เซอร์)
  2. พิมพ์ชื่อของคุณให้ตรงกับที่เจ้าของตั้งไว้ → กด เข้าใช้งาน
  3. เชื่อม LINE เพื่อรับแจ้งเตือน: ตั้งค่า → บัญชี → เชื่อม LINE → กด อนุญาต และเพิ่มเพื่อน Fit Routine ถ้ามีช่องให้ติ๊ก
  4. บันทึกการเทรน: เมนู เทรน → + บันทึกการเทรน → กด ดึงท่าจากแผน หรือ ใช้ครั้งก่อน → กรอก kg × ครั้ง ของแต่ละเซ็ต → แนบรูป (ถ้ามี) → บันทึก
  5. ปรับแผนซ้อม: ตั้งค่า → แผนซ้อม → แก้ท่า เซ็ต ครั้ง kg ของแต่ละวัน ระบบบันทึกให้อัตโนมัติ
อยากใช้เหมือนแอป หลังเข้าใช้แล้ว กดปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม จากนั้นเปิดจากไอคอนได้เลย ถ้าไอคอนถามลิงก์เชิญ ให้วางลิงก์เดิมในช่อง มีลิงก์เชิญ?
ข้อควรระวัง ถ้ากด ออกจากระบบ ต้องเปิดลิงก์เชิญและพิมพ์ชื่อใหม่อีกครั้ง

4หน้า "วันนี้" ทุกคนดูได้

หน้าหลักของแต่ละวัน ใช้ปุ่ม ‹ › หรือกดที่วันที่เพื่อดูวันอื่น และกด กลับวันนี้ เพื่อกลับมาวันปัจจุบัน

พลังงานวันนี้

ตัวเลขใหญ่คือแคลอรี่ที่ยังกินได้อีก เทียบกับเป้าที่ปรับตามการออกกำลังกายของวันนั้น และมีแถบโปรตีน คาร์บ ไขมัน

โปรตีนยังขาด เจ้าของ

เสนอ 2–3 ทางเลือกที่เติมโปรตีนได้ใกล้เป้าที่สุด (รวมเวย์ 30 g/สกู๊ป) กด กินแล้ว บันทึก แล้วระบบบันทึกให้ทันที หลัง 20:00 จะเสนอเฉพาะกรีกโยเกิร์ตกับมิกซ์เบอร์รี

สมดุลแคลอรี่

แสดง BMR × กิจกรรม + ออกกำลังกาย = เผาผลาญทั้งวัน พร้อมข้อสังเกตประจำวัน

ความเคลื่อนไหวในทีม

พิมพ์ข้อความ เช่น "วันนี้ปวดเข่า ขอเบาขา" แนบไฟล์ได้ด้วยปุ่ม 📎 แล้วกด ส่ง คนในทีมที่เปิดรับจะได้รับแจ้งเตือนทาง LINE

น้ำดื่ม เจ้าของ

กด + 250 มล. + 500 มล. + 1 ลิตร กดผิดใช้ − 250 วันที่ออกกำลังกาย เป้าจะเพิ่มอีก 500 มล.

แผนวันนี้

แสดงคาร์ดิโอและท่าเวทตามแผน ถ้าทำคาร์ดิโอแล้วกด ทำแล้ว บันทึกเลย ถ้าเป็นวันเวท เทรนเนอร์กด บันทึกการเทรนวันนี้ ได้จากตรงนี้

บันทึกอาหาร เจ้าของ

  1. ที่หัวข้อมื้อ (เช้า / กลางวัน / ว่าง / เย็น) กด + เพิ่ม แล้วเลือกมื้อที่แถบด้านบนของหน้าต่าง
  2. ถ้ามีรูปอาหาร ฉลาก หรือใบเสร็จ กด 📎 แนบ ก่อน ไฟล์นี้จะผูกกับทุกรายการที่เพิ่มในครั้งนี้
  3. ประกอบจานเอง (วิธีหลัก) เลือกวัตถุดิบแต่ละอย่าง แล้วใส่น้ำหนักที่ชั่งได้เป็นกรัม เช่น แซลมอน 200 กรัม · กุ้ง 100 กรัม · ข้าวสวย 150 กรัม แอปจะแปลงเป็น kcal โปรตีน คาร์บ และไขมันให้ทันที กด + เพิ่มวัตถุดิบ เพื่อเพิ่มแถว แล้วกด เพิ่มจานนี้ลงบันทึก
  4. เลือก (ดิบ) ถ้าชั่งก่อนทำอาหาร เลือก (สุก) ถ้าชั่งหลังทำสุกแล้ว เช่น ข้าวสาร (ดิบ ก่อนหุง) กับ ข้าวสวย (หุงสุกแล้ว) ให้ค่าไม่เท่ากัน
  5. ทางเลือกอื่น: เลือกทีละอย่างจากรายการ หรือ กรอกค่าโภชนาการเอง (จากฉลาก) ช่องโปรตีน คาร์บ และไขมันในแบบกรอกเองคือ กรัมของสารอาหารตามฉลาก ไม่ใช่น้ำหนักอาหาร
  6. จะแนบรูปทั้งมื้อก็ได้ โดยกด แนบรูปมื้อนี้ ที่หัวข้อมื้อ
แก้ปริมาณ กดที่รายการอาหาร ถ้าเป็นจานที่ประกอบเอง จะแก้น้ำหนักวัตถุดิบทีละอย่างได้ ถ้าเป็นรายการที่มีน้ำหนักกรัม แก้กรัมได้โดยตรง แล้วแอปคำนวณใหม่ให้ ส่วนรายการแบบจาน/ชิ้น ให้ใส่เป็นจำนวนเท่า (0.5 = ครึ่ง) ไม่ใช่กรัม ถ้าอยากใส่เป็นกรัม ให้ลบรายการนั้นแล้วเพิ่มใหม่ด้วย "ประกอบจานเอง"

ออกกำลังกาย เจ้าของ

กด + เพิ่ม → เลือกประเภท (ว่ายน้ำ เดิน ลู่วิ่ง ฯลฯ) → ใส่นาที → ถ้านาฬิกาบอก kcal ให้ใส่ช่อง kcal จากนาฬิกา ระบบจะใช้ตัวเลขนั้นแทนค่าประมาณ → แนบหน้าจอนาฬิกา → บันทึก

ส่งสรุป

คัดลอกสรุปวันนี้ หรือ คัดลอกสรุป 7 วัน แล้วนำไปวางในแชตไหนก็ได้ ส่วนเจ้าของกด ส่งสรุปวันนี้ทาง LINE เพื่อส่งถึงผู้รับทุกคนได้ทันที

5หน้า "เทรน" เทรนเนอร์บันทึก

รวมทุก session เวทกับเทรนเนอร์ ด้านบนแสดงจำนวน session สะสม จำนวนครั้งในสัปดาห์นี้ และวันที่เทรนครั้งล่าสุด

บันทึกการเทรน

  1. กด + บันทึกการเทรน → เลือกวันที่ ประเภท (Push / Pull / Legs …) และเวลา
  2. กด ดึงท่าจากแผน เพื่อใส่ท่าจากแผนซ้อมของวันนั้น หรือ ใช้ครั้งก่อน (ท่า + น้ำหนักเดิม) เพื่อคัดลอก session ประเภทเดียวกันครั้งล่าสุด
  3. กรอก kg × ครั้ง ทีละเซ็ต กด + เซ็ต + เพิ่มท่า ถ้าต้องการเพิ่ม ใส่หมายเหตุรายท่าได้ เช่น "ฟอร์มดีขึ้น"
  4. แนบรูปหรือวิดีโอสั้นในช่อง แนบรูป/ไฟล์การเทรน → กด บันทึก

พัฒนาการรายท่า

ตารางเทียบครั้งแรกกับครั้งล่าสุดของแต่ละท่า เปลี่ยนแปลงเป็น % โดยคำนวณจาก 1RM โดยประมาณ (สูตร Epley) กดชื่อท่าเพื่อดูกราฟ

ประวัติการเทรน

ทุก session พร้อมปริมาณรวม (kg × ครั้ง) กด แก้ไข เพื่อแก้ หรือกด ใช้เป็นแม่แบบวันนี้ เพื่อเริ่มบันทึกวันนี้จาก session นั้น

6หน้า "ครัว" ทุกคนดูได้

สมุดเมนูของฉัน

เมนูที่เก็บไว้ทำซ้ำ มีวัตถุดิบ วิธีทำ และรูปผลงาน กรองตามมื้อได้ เลือกมื้อแล้วกด กินเมนูนี้ · บันทึก ระบบบันทึกอาหารให้ทันที กด เพิ่มรูปผลงาน เพื่อเก็บรูปที่ทำจริง

ของในครัว เจ้าของ

ใส่จำนวนแล้วกด ใช้ไป หรือ เติม แอปคำนวณการใช้เฉลี่ยต่อวันและวันที่ของจะหมด ของที่ใกล้หมดจะขึ้นในแถบ ควรซื้อเพิ่ม กด เพิ่มวัตถุดิบ เพื่อลงของใหม่พร้อมรูปใบเสร็จ

วันนี้ทำอะไรกินดี

พิมพ์ของที่มี (หรือปล่อยว่างเพื่อใช้ของในครัว) → หาเมนูจากของที่มี แอปจะบอกว่ามีอะไรครบแล้ว (✓) และขาดอะไร (+) กด เก็บลงสมุดเมนู ถ้าชอบเมนูนั้น · ถ้าในครัวไม่มีโปรตีนของสูตร แต่มีโปรตีนอื่น แอปสลับให้อัตโนมัติ เช่น มีอกไก่แต่ไม่มีกุ้ง จะเห็น "ต้มยำไก่น้ำใส" พร้อมป้าย 🔁

เมนูทั้งวันตามเป้า

เลือก วันซ้อม หรือ วันพัก แอปจัดเมนู 4 มื้อให้ตรงเป้า kcal และโปรตีน เลือก โปรตีนกลางวัน / โปรตีนเย็น ได้ (เช่น เย็นนี้อยากกินไก่) แอปปรับกรัมให้โปรตีนถึงเป้าเอง ถ้าไม่ชอบกด สุ่มเมนูใหม่ ถ้าจะกินตามนี้กด เพิ่มทั้งหมดลงบันทึก

เพิ่มเมนูเอง เจ้าของ

  1. หน้า ครัว → การ์ด สมุดเมนูของฉัน → กด + เพิ่มเมนูเอง
  2. ใส่ชื่อเมนู เลือกมื้อที่เหมาะ (เลือกได้หลายมื้อ) และเวลาทำ
  3. ในส่วน วัตถุดิบหลัก เลือกวัตถุดิบที่มีแคลอรี่ เช่น กุ้ง ข้าว น้ำมัน แล้วใส่น้ำหนักเป็นกรัม → แอปคำนวณ kcal โปรตีน คาร์บ ไขมันให้เอง กด + เพิ่มวัตถุดิบ ได้หลายอย่าง
  4. พิมพ์เครื่องปรุง/ผัก และวิธีทำ บรรทัดละ 1 อย่าง (ถ้ารู้ค่าโภชนาการจากที่อื่น แก้ตัวเลขในช่อง kcal/P/C/F ได้เลย)
  5. กด บันทึกลงสมุดเมนู · จะแก้ภายหลังกด แก้ไข ใต้เมนูนั้น

สลับวัตถุดิบ เช่น เปลี่ยนกุ้งเป็นไก่ เจ้าของ

  1. กด 🔁 สลับวัตถุดิบ ใต้เมนูในสมุดเมนู หรือใต้เมนูที่แอปแนะนำ
  2. แอปบอกโปรตีนหลักของเมนู (เช่น กุ้ง) → เลือกสิ่งที่อยากใช้แทน: ไก่ หมู เนื้อวัว ปลา แซลมอน ปลาหมึก ทูน่า เต้าหู้ กุ้ง
  3. เลือกปริมาณ: ให้โปรตีนใกล้เคียงเดิม (แนะนำ แอปปรับกรัมให้) หรือ กรัมเท่าเดิม
  4. ดูตัวอย่าง: ชื่อเมนูใหม่ วิธีทำที่เปลี่ยนคำและกรัมแล้ว และ kcal/P/C/F ใหม่เทียบกับเดิม
  5. กด บันทึกเป็นเมนูใหม่ (เก็บเมนูเดิมไว้ด้วย) หรือ แทนที่เมนูเดิม

ตัวอย่าง: ต้มยำกุ้งน้ำใส (กุ้ง 120 g) → ต้มยำไก่น้ำใส (อกไก่ 90 g) โปรตีนใกล้เคียงเดิม · ถ้าวิธีทำบางขั้นยังไม่เข้ากับวัตถุดิบใหม่ (เช่นเวลาต้ม) กด แก้ไข ปรับได้

อยากได้เมนูใหม่เพิ่ม ขอในแชตกับอินังได้เลย เช่น "ขอเมนูเย็นโปรตีน 30 g ใช้ไก่หรือปลา 3 เมนู แบบ FIT1" แล้วก๊อปมาวางที่ วางจากอินัง เมนูจะเข้าสมุดเมนูอัตโนมัติ (ดูข้อ 12)
ข้อจำกัดอาหาร เมนูที่แอปสุ่มให้ไม่ใช้ข้าวโอ๊ต และไม่สุ่มไก่ หมู หรือเนื้อวัวให้เอง · ไก่ หมู เนื้อวัว จะใช้เฉพาะตอนที่เลือกเอง (สลับวัตถุดิบ / เลือกโปรตีนกลางวัน-เย็น) หรือมีอยู่ในของในครัว · หมูและเนื้อวัวในแอปเป็นส่วนไม่ติดมัน (หมูสันใน สันนอกเลาะมัน หมูสับไม่ติดมัน เนื้อสันใน/สะโพก) · ข้อมูลที่แพ้/เลี่ยงแก้ได้ที่หน้าร่างกาย → อาหารที่แพ้ / เลี่ยง

7หน้า "ร่างกาย" ทุกคนดูได้

  • ร่างกายตอนนี้ แสดงน้ำหนัก มวลกล้ามเนื้อ (SMM) ไขมัน % BMI BMR และ TDEE วันซ้อม รวมทั้งเวลาที่คาดว่าจะถึงเป้ากล้ามเนื้อ
  • ข้อมูลพื้นฐาน เจ้าของ ชื่อ อายุ ส่วนสูง เวลากินมื้อสุดท้าย อาหารที่แพ้/เลี่ยง ข้อจำกัดร่างกาย ข้อมูลส่วนนี้ใช้คำนวณและแนะนำเมนู
  • สัดส่วนร่างกาย ตารางเทียบครั้งแรกกับล่าสุดของทุกจุดวัด
  • แนวโน้ม กราฟน้ำหนัก มวลกล้ามเนื้อ ไขมัน % และรอบเอว พร้อมเส้นเป้าหมาย
  • ประวัติผลวัด ทุกครั้งที่วัด พร้อมป้ายหลักฐาน

เพิ่มผลวัด เจ้าของ

  1. เลือกวันที่วัด → กรอกค่าจากใบ InBody (น้ำหนัก SMM ไขมัน kg/% BMR ไขมันช่องท้อง น้ำในร่างกาย) กรอกเฉพาะค่าที่มีก็ได้
  2. ถ้าวัดด้วยสายวัด เปิด สัดส่วนร่างกาย (สายวัด) → เลือก cm หรือ นิ้ว (แปลงให้) → กรอกตัวเลข
  3. กด แนบใบผลวัด (รูป/PDF) → บันทึกผลวัด

8หน้า "ภาพรวม" ทุกคนดูได้

  • กราฟสมดุลแคลอรี่ 14 วัน แท่งทองคือขาดดุล (ลดไขมัน) แท่งส้มคือเกินดุล จุดเขียวใต้แท่งคือวันที่โปรตีนถึงเป้า
  • สรุปตัวเลข จำนวนวันที่บันทึก ค่าเฉลี่ยที่กิน โปรตีนเฉลี่ย โปรตีนที่ขาดต่อวัน จำนวนครั้งที่เทรน และไขมันที่เปลี่ยนโดยประมาณ
  • ตารางรายวัน มีคอลัมน์ หลักฐาน บอกจำนวนรายการที่แนบไฟล์ เช่น 5/6 กด เปิด เพื่อไปดูวันนั้น

9หน้า "ตั้งค่า"

ปุ่มใช้ทำอะไรใครเห็น
เป้าหมายระดับกิจกรรม เป้าแคลอรี่ (ลด/คง/เพิ่ม หรือกำหนดเอง) TDEE จากเทรนเนอร์ เป้าน้ำ สัดส่วน P/C/F และเป้ากล้ามเนื้อ/ไขมันทุกคน (แก้ได้เฉพาะเจ้าของ)
แผนซ้อมแผนรายสัปดาห์ จันทร์–อาทิตย์ คาร์ดิโอ ท่าเวท เซ็ต ครั้ง kgทุกคน (แก้ได้: เจ้าของ + เทรนเนอร์)
สมาชิกเพิ่มสมาชิก คัดลอกลิงก์เชิญ ปิด/เปิดสิทธิ์ สร้างลิงก์ใหม่ ออกจากทุกอุปกรณ์เจ้าของ
LINEเชื่อมระบบแจ้งเตือน และเลือกว่าใครได้รับเรื่องอะไรเจ้าของ
ข้อมูลนำเข้าไฟล์ .json · ดาวน์โหลดสำรองข้อมูล · เปิดช่องวางจากอินังเจ้าของ
บัญชีเชื่อม LINE ของตัวเอง ส่งข้อความทดสอบ ออกจากระบบทุกคน

จัดการสมาชิก เจ้าของ

  • ปิดสิทธิ์ หยุดการเข้าถึงชั่วคราว กด เปิดสิทธิ์ เพื่อให้กลับมาใช้ได้
  • สร้างลิงก์ใหม่ ใช้เมื่อลิงก์เชิญหลุดไปถึงคนอื่น ลิงก์เดิมจะใช้ไม่ได้ทันที
  • ออกจากทุกอุปกรณ์ ทุกเครื่องที่สมาชิกคนนั้นเคยเข้าจะหลุดออก และต้องใช้ลิงก์เชิญเข้าใหม่
สำรองข้อมูลเดือนละครั้ง ตั้งค่า → ข้อมูล → ดาวน์โหลดสำรองข้อมูล เก็บไฟล์ไว้ใน iCloud หรือ Google Drive (ห้ามอัปโหลดไฟล์นี้ขึ้น GitHub เพราะ repo เป็นสาธารณะ)

10แจ้งเตือน LINE

แจ้งเตือนจะส่งเป็นแชต 1:1 จากบัญชี LINE Fit Routine ถึงแต่ละคน ไม่ต้องสร้างกลุ่ม

เชื่อม LINE ของตัวเอง ทุกคน

  1. ตั้งค่า → บัญชี → เชื่อม LINE
  2. LINE จะเปิดหน้าขออนุญาต → กด อนุญาต ถ้ามีหน้าชวนเพิ่มเพื่อน Fit Routine ให้กดเพิ่มเพื่อน (ถ้าเป็นเพื่อนอยู่แล้วจะขึ้นว่า "เพิ่มเพื่อนแล้ว" ให้กด กลับ)
  3. ขึ้นหน้า เชื่อม LINE สำเร็จ ✅ → กด กลับไปที่ Fit Routine
  4. จะได้รับข้อความใน LINE ว่า "เชื่อม LINE กับ Fit Routine แล้ว ✅" กด ส่งข้อความทดสอบถึงฉัน เพื่อลองได้

เลือกว่าใครได้รับเรื่องอะไร เจ้าของ

ตั้งค่า → LINE → กล่อง ใครได้รับอะไร ติ๊ก อนุญาต/รับแจ้งเตือน ของแต่ละคน แล้วกดเลือกหัวข้อ (ปุ่มสีทอง = รับ)

หัวข้อส่งเมื่อค่าเริ่มต้น
อาหารบันทึกหรือแก้รายการอาหารเทรนเนอร์
การเทรนเทรนเนอร์บันทึกหรือแก้ session เวทเจ้าของ
ออกกำลังกายบันทึกคาร์ดิโอหรือออกกำลังกายอื่นเทรนเนอร์
ผลวัดร่างกายบันทึกผล InBody หรือสายวัดเทรนเนอร์
ข้อความในทีมมีคนส่งข้อความในหน้าวันนี้ทุกคน
เมนู/ครัวเพิ่มเมนูลงสมุดเมนูปิดไว้
  • คนที่เป็นผู้อัปเดตจะไม่ได้รับแจ้งเตือนเรื่องของตัวเอง
  • การอัปเดตหลายรายการภายใน 45 วินาที จะรวมเป็นข้อความเดียว เพื่อประหยัดโควตา
  • บัญชี LINE แบบฟรีส่งได้ประมาณ 300 ข้อความต่อเดือน
  • ถ้าจะหยุดแจ้งเตือนของใคร ให้เอาติ๊ก อนุญาต/รับแจ้งเตือน ออก หรือกด ยกเลิกการเชื่อม

11หลักฐานแนบ ทุกคน

ทุกจุดที่บันทึกข้อมูลมีปุ่ม 📎 ไว้แนบไฟล์ เพื่ออ้างอิงว่าทำจริง แอปไม่อ่านหรือวิเคราะห์ไฟล์ เก็บไว้ให้ดูเท่านั้น

ที่ควรแนบอะไร
อาหารรูปอาหาร ฉลากโภชนาการ ใบเสร็จ (แนบทั้งมื้อหรือแนบรายรายการก็ได้)
ออกกำลังกายหน้าจอนาฬิกา หรือแอปว่ายน้ำ
การเทรนรูปหรือไฟล์จากเทรนเนอร์ในแต่ละ session
ผลวัดใบ InBody (รูปหรือ PDF) รูปสายวัด
น้ำดื่ม · ของในครัว · เมนู · ข้อความรูปขวดน้ำ ใบเสร็จ รูปเมนูที่ทำ ไฟล์ประกอบข้อความ
  • รายการที่มีไฟล์แนบจะมีป้ายสีเขียว รายการที่ยังไม่มีจะขึ้นว่า "ไม่มีหลักฐาน"
  • หน้าวันนี้ หน้าภาพรวม และสรุปที่ส่งให้เทรนเนอร์ จะบอกสัดส่วนรายการที่มีหลักฐาน เช่น 5/6
  • รูปจะถูกย่ออัตโนมัติ ไฟล์อื่น (เช่น PDF) ต้องไม่เกิน 700 KB
  • แตะรูปเล็กเพื่อดูรูปใหญ่

12วางจากอินัง เจ้าของ

ส่งรูปอาหาร หรือเล่าว่ากินอะไร/ออกกำลังกายอะไร ในแชตกับอินัง (Claude) อินังจะตอบเป็นสรุป kcal โปรตีน คาร์บ ไขมัน แล้วก๊อปมาวางในแอปได้เลย รองรับทั้งข้อความธรรมดาและแบบ FIT1 {…}

  1. ก๊อปข้อความสรุปอาหารจากแชตกับอินัง เช่น ข้าวสวยสุก 220 กรัม → ประมาณ 285 kcal / โปรตีน ~5 g / คาร์บ ~64 g / ไขมัน ~1 g
  2. ในแอป หน้าวันนี้ กด วางจากอินัง → เลือก นำเข้าเป็นมื้อ เช้า กลางวัน ว่าง เย็น หรือ ตามข้อความ (ใช้มื้อที่เขียนไว้ในข้อความ เช่น "มื้อเช้า")
  3. วางข้อความ → กด 📎 แนบ ใส่รูปเดียวกับที่ส่งให้อินัง เพื่อเก็บเป็นหลักฐาน
  4. กด ตรวจสอบ แอปจะแสดงรายการที่อ่านได้ทีละบรรทัด พร้อมมื้อ kcal และ P C F → ถ้าถูกต้องกด นำเข้า
  • บรรทัด "รวม…" ในข้อความจะถูกข้ามไป จะได้ไม่นับซ้ำ
  • ถ้ารายการไหนมีน้ำหนักเป็นกรัม นำเข้าแล้วกดที่รายการเพื่อแก้กรัมได้ แอปคำนวณใหม่ให้
  • แบบ FIT1 นำเข้าได้มากกว่าอาหาร คือออกกำลังกาย น้ำ ของเข้า/ออกครัว ผลวัด และเมนูใหม่ลงสมุดเมนู

13แก้ปัญหาที่พบบ่อย

รูปหลักฐานไม่ขึ้น เห็นแค่ปุ่มเขียว

ดึงหน้าจอลงเพื่อรีเฟรช หรือกดปุ่มรีเฟรชของเบราว์เซอร์ ถ้าเน็ตช้ารูปจะโหลดตามมาทีหลัง ถ้ายังไม่ขึ้น ให้ปิดแอปแล้วเปิดใหม่

เทรนเนอร์เข้าไม่ได้ ขึ้นว่าชื่อไม่ตรง

ชื่อต้องพิมพ์ตรงกับที่เจ้าของตั้งไว้ใน ตั้งค่า → สมาชิก (เว้นวรรคได้ ตัวพิมพ์เล็ก/ใหญ่ไม่มีผล) และสิทธิ์ต้องไม่ถูกปิดอยู่

ลิงก์เชิญหลุดไปถึงคนอื่น

กด สร้างลิงก์ใหม่ ที่สมาชิกคนนั้น ลิงก์เดิมจะใช้ไม่ได้ทันที แล้วส่งลิงก์ใหม่ให้คนที่ถูกต้อง ถ้ามีคนแปลกหน้าเข้ามาแล้ว ให้กด ออกจากทุกอุปกรณ์ ด้วย

ไม่ได้รับแจ้งเตือนใน LINE
  • ตรวจว่าเชื่อม LINE แล้ว (ตั้งค่า → LINE ชื่อคนนั้นต้องมีป้ายสีเขียว "LINE: …")
  • ต้องเป็นเพื่อนกับ Fit Routine และไม่ได้บล็อก
  • ต้องติ๊ก อนุญาต/รับแจ้งเตือน และเลือกหัวข้อนั้นไว้
  • รอประมาณ 45 วินาที เพราะระบบรวมข้อความก่อนส่ง
  • กด ตรวจการเชื่อมต่อ ต้องขึ้น ✓ ครบทุกตัว
กดเข้าสู่ระบบด้วย Google แล้วไม่มีอะไรเกิดขึ้น

Safari อาจบล็อกหน้าต่างป๊อปอัป ให้ไปที่ การตั้งค่า iPad → Safari → ปิด "บล็อกป๊อปอัป" แล้วลองใหม่

แอปบนหน้าจอโฮมให้ล็อกอินใหม่

เป็นเรื่องปกติของ iPhone/iPad เพราะแอปบนหน้าจอโฮมแยกข้อมูลจาก Safari ให้ใช้ลิงก์สิทธิ์ อุปกรณ์อื่นของฉัน ตามข้อ 2

เน็ตหลุดตอนบันทึก

แอปเก็บข้อมูลไว้ในเครื่องก่อน แล้วซิงก์ขึ้นระบบเองเมื่อเน็ตกลับมา อย่าเพิ่งล้างข้อมูลเว็บไซต์ของเบราว์เซอร์จนกว่าจะออนไลน์

ขึ้นว่า "คุณไม่มีสิทธิ์แก้ข้อมูลส่วนนี้"

บัญชีนั้นไม่มีสิทธิ์แก้ข้อมูลส่วนนั้น เช่น เทรนเนอร์แก้บันทึกอาหารไม่ได้ ดูตารางสิทธิ์ในข้อ 1
